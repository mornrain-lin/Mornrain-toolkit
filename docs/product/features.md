# 产品功能需求

一个纯前端、开源免费的在线工具箱，所有处理都在浏览器本地完成，文件与文本不上传。

## 核心定位
- 隐私安全：纯客户端运行，数据不出本机
- 完全免费：无付费墙、无广告
- 打开即用：无需注册登录
- 响应式：桌面与移动端均可使用

## 工具清单（17 个）

### 图片工具
1. 图片压缩：可调质量，展示压缩前后体积与减少比例
2. 图片格式转换：PNG / JPEG / WebP 互转
3. 二维码生成：自定义尺寸与前景/背景色，导出 PNG

### 文本工具
4. JSON 格式化：格式化 / 压缩 / 校验，给出错误提示
5. Base64 编解码：支持中文与 emoji
6. URL 编解码：用于接口调试
7. 大小写转换：大写 / 小写 / 标题 / 驼峰 / 下划线 / 中划线
8. 字数统计：字符、单词、行数、段落、阅读时间
9. Markdown 预览：实时渲染，安全过滤，可导出 HTML
10. 正则测试：高亮匹配结果，支持 g/i/m 等标志位

### 开发工具
11. 密码生成器：基于浏览器加密接口，带强度评估
12. UUID 生成器：批量生成
13. 哈希生成：SHA-1 / 256 / 384 / 512
14. 时间戳转换：Unix 时间戳与日期互转
15. 进制转换：二进制 / 八进制 / 十进制 / 十六进制

### 换算工具
16. 颜色转换：HEX / RGB / HSL 互转，取色器
17. 单位换算：长度 / 重量 / 温度

## 体验要求
- 首页：分类展示 + 搜索，一键进入工具
- 全局搜索：顶栏可快速定位工具
- 主题：深色为默认，可切换浅色，偏好本地保存
- 导航：左侧分类导航，移动端折叠为抽屉
